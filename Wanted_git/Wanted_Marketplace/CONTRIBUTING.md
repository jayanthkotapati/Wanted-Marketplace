# Contributing

Thanks for your interest in improving Wanted Marketplace!

1. Fork the repository and create a branch for your change.
2. Keep credentials, API keys, database URLs, and personal data out of commits.
3. Describe the change and how you tested it in your pull request.
4. For security issues, do not publish exploit details in a public issue; contact the repository owner privately.

This repository is an MVP starter. Authentication, payment processing, location tracking, and masked calling require further implementation and security review before production use.
